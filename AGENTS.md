# AGENTS.md

PhishGuard-AI: phishing detection pipeline (genetic score → ReAct agent → Gmail actions). Python 3.10+, Windows-primary (README uses `.venv\Scripts\`), but code is cross-platform.

## Commands

Tests use `pytest` (configured in `pyproject.toml`), and `scripts/verify.py` runs the full gate (lint + mypy + tests + coverage + branch checks). The legacy `tests/test_pipeline.py` is a plain PASS/FAIL runner that `sys.exit(0|1)`.

```powershell
# Install
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# Run the full verification suite (lint + types + tests + coverage)
.venv\Scripts\python.exe scripts/verify.py

# Run only the unit tests
.venv\Scripts\python.exe -m pytest tests/unit/

# Run the legacy fixture pipeline (plain runner)
.venv\Scripts\python.exe tests/test_pipeline.py

# Run the Gmail poller (long-running loop, 30s interval)
.venv\Scripts\python.exe src/gmail_integration/gmail_poller.py

# Run the API REST server (spec 012)
.venv\Scripts\python.exe -m src.api --host 0.0.0.0 --port 8000
# Or with uvicorn directly:
.venv\Scripts\uvicorn.exe src.api.app:create_app --factory --host 0.0.0.0 --port 8000
```

To run a single fixture: temporarily move the other `tests/fixtures/*.json` files out — the runner globs every `*.json` in `tests/fixtures/` and there is no filter flag.

## Test prerequisites (easy to miss)

`tests/test_pipeline.py` calls `analyze_email()`, which lazily builds the Gemini LLM and (for the `ai_agent` fixture, score 30–75) the ReAct agent + MongoDB vector retriever. Required env in `.env`:

- `GOOGLE_API_KEY` — mandatory for any test run (LLM is built up front in `analyze_email`).
- `MONGODB_ATLAS_CLUSTER_URI` — needed for the `ai_agent` case (RAG retriever); missing it makes that case fail/degrade, not skip.

Optional: `VT_API_KEY`, `JIRA_*`. Tools degrade gracefully when absent (logged warnings, not errors).

## Architecture notes not obvious from filenames

- **Package root is `src/`**, imported as `src.level2_agent...`, `src.level3_logic...`, `src.gmail_integration...`. There is no installed package; scripts rely on `sys.path.insert(0, PROJECT_ROOT)` and `sys.path.insert(0, SRC_DIR)` at the top of `tests/test_pipeline.py` and `gmail_poller.py`. Do not rename `src/` or move modules without updating these inserts — there is no `src/__init__.py` and no editable install.
- **Normalization pipeline** lives in `src/level2_agent/normalizacion/` (spec 002). Public API (imported from the package `__init__`): `normalizar_desde_gmail` / `normalizar_desde_eml` / `normalizar_desde_api` → `EmailData`, plus `enmascarar_para_terceros` / `enmascarar_texto` for PII. The Gmail poller now calls `get_message_raw` + `normalizar_desde_gmail` (the legacy `email_to_emaildata.py` adapter is kept for compatibility but is no longer on the poller path). `EmailData` gained fields (`cabeceras`, `texto_limpio`, `urls`, `adjuntos`, `origen`, `banderas`, `revision_manual`); `htmlBody` is `exclude=True` so it is never persisted. Constants (5 hard limits + flags) are in `normalizacion/limites.py`, PII regexes in `normalizacion/enmascarado.py`.
- **Header flags** live in `src/level2_agent/banderas/` (spec 003, module M03). Public API (from the package `__init__`): `evaluar_banderas(email_data, config=..., ahora=..., cliente_rdap=...)` → `ResultadoBanderas` (flags + `estados_autenticacion` + `puntos_totales` capped at 60), plus `ConfigBanderas` / `ConfiguracionError`. It is **not yet wired into `agent.py`** — consumed by future specs 007/008. The 16-flag catalog (code → severity + points) is the single source of truth in `banderas/modelos.py` (`CATALOGO_BANDERAS`, Art. VI.2); strategies never invent weights. `ahora` and `cliente_rdap` are injected for determinism (no network in tests). Config via env (`AUTHSERV_ID`, `DOMINIOS_PROPIOS`, ...), see `.env.example`; `tldextract` uses the bundled PSL (`suffix_list_urls=()`), offline.
- **URL analysis module** lives in `src/level2_agent/analisis_urls/` (spec 004, M04b). Public API (package `__init__`): `analizar_urls(email_data, config=None, deps=None) -> ResultadoURLs`, plus `ConfigURLs` / `ConfiguracionError` and `DependenciasURLs` / `dependencias_por_defecto`. It is intentionally **NOT wired** into `agent.py`/the poller (specs 006/007/008 will consume it); it never touches `models.py` or `normalizacion/`. Catalog codes/severities/points are the literal 13 of `docs/PLAN_MODIFICACIONES_PHISHGUARD.md` 5.2 in `modelos.CATALOGO_URL` — never invent weights (`bandera()` copies them). Expansion is SSRF-guarded **per hop** (`ssrf.py`: FR-004 networks + `is_global`/multicast), capped at `TOPE_SALTOS=5` / `TIMEOUT_URL_SEGUNDOS=5.0` (injected clock), and never reads response bodies. Config env vars (comma-separated, defaults in `configuracion.py`/research D8): `ACORTADORES`, `TLD_RIESGO`, `PARAMETROS_TRACKING`, `PARAMETROS_SENSIBLES` (the 7 literal FR-007 names), `URL_SUBDOMINIOS_MAX`. Tests use doubles from `tests/unit/dobles_red.py` (fake DNS/HTTP/clock + loopback server) — zero real network.
- **Attachment analysis** lives in `src/level2_agent/adjuntos/` (spec 005, module M05). Public API (package `__init__`): `analizar_adjunto(nombre, tipo_declarado, payload, config=None)` → `AnalisisAdjunto` (SHA-256/MD5/SHA-1 + `tipo_real` + banderas of catalog 5.3), plus `ConfigAdjuntos` / `ConfiguracionError` / `CATALOGO_ADJUNTOS`. It is intentionally **NOT wired** into `agent.py`/the poller (specs 006/008 will consume it); it never touches `models.py` or `normalizacion/`. All analysis is **in memory** — never writes to disk, never executes, never uses network (FR-006, verified by AST gate + tmpdir test). Catalog codes/severities/points are the literal 9 `ADJ_*` of `docs/PLAN_MODIFICACIONES_PHISHGUARD.md` 5.3 in `modelos.CATALOGO_ADJUNTOS` — never invent weights (`bandera()` copies them). Detectors use Strategy + Registry pattern; `oletools` (OLE2 macros) is behind an Adapter. Zip inspection uses streamed reading with hard caps (100 entries / 100 MiB / 100:1 ratio) — aborts before exhausting memory. Config env vars (comma-separated, defaults in `configuracion.py`/research D10): `ADJ_EXTENSIONES_RIESGO`, `ADJ_EXTENSIONES_HTML`, `ADJ_EXTENSIONES_DOCUMENTO`, `ADJ_LIMITE_ENTRADAS_ZIP`, `ADJ_LIMITE_DESCOMPRIMIDO_ZIP`, `ADJ_RATIO_MAXIMO_ZIP`. EICAR test vector is generated in memory (`tests/unit/vector_eicar.py`), never stored on disk (SC-003).
- **VirusTotal client** lives in `src/level2_agent/virustotal/` (spec 006, module M06). Public API (package `__init__`): `consultar_archivo` / `consultar_url` / `consultar_dominio` / `consultar_ip` → `ResultadoVT`, plus `clasificar_stats` (pure M06.4 table), `presupuesto_nuevo`, `ConfigVT` / `DependenciasVT` / `dependencias_por_defecto`, `CATALOGO_VT`; `subir_archivo` / `enviar_url_desconocida` live in `envios.py` and emit **zero requests** while `VT_UPLOAD_UNKNOWN` / `VT_SUBMIT_UNKNOWN_URLS` are false (AC-VT-09, D13). It is intentionally **NOT wired** into `agent.py`/the poller (specs 007/008 consume it); it never touches `models.py`. Public API is **sync** wrapping `asyncio.run` over async httpx (D2). Flows: validate → cache → key → circuit breaker → daily quota → budget → 4/min bucket → GET with 429/5xx retries (1/2/4 s + jitter, `Retry-After` honored) → M06.4 classification → cache **only real verdicts** (clarify FR-005; 7 d file / 24 h URL-domain-IP / 1 h 404). Namespaces: Mongo `phishguard.vt_cache` (TTL index on `expira_en`, `[VERIFICAR]` in quickstart V1) and `phishguard.vt_contador` (daily 500, survives restarts); both fall back to in-memory with a warning when `MONGODB_ATLAS_CLUSTER_URI` is missing (III.9). Default quota is the public 4/min + 500/day; `VT_TIER=premium` honors `VT_RPM`/`VT_DAILY` **only when set explicitly** (clarify). Budget: 10 external calls per email (`VT_MAX_POR_CORREO`) shared by the caller via `presupuesto_nuevo` — omitting it means loose queries (contract §1). Indicator errors never raise — they become `desconocida` (G12). Env vars: `VT_API_KEY`, `VT_TIER`, `VT_RPM`, `VT_DAILY`, `VT_MAX_POR_CORREO`, `VT_UPLOAD_UNKNOWN`, `VT_SUBMIT_UNKNOWN_URLS`, `VT_UMBRAL_MALICIOSA`, `VT_UMBRAL_SOSPECHOSA`, `VT_UMBRAL_LIMPIA` (see `.env.example`). `httpx==0.28.1` is the only new dependency; the key is built only inside the request (D10) and never logged (FR-009). Test doubles: `tests/unit/dobles_vt.py` (`ClienteDoble` fails on unregistered requests; recorded responses in `tests/unit/respuestas_vt/`, never `tests/fixtures/`).
- **Decision engine** lives in `src/level2_agent/decision/` (spec 008, module M09). Public API (package `__init__`): `evaluar_veredicto(entrada: EntradaMotor) -> VeredictoMotor`, plus `EntradaMotor`, `VeredictoMotor`, `VerificacionIncompleta`, `UMBRAL_BAJO=30`, `UMBRAL_ALTO=76`. It is **now wired** into `agent.py` via the spec 009 refactor (consumed by `_agente_zona_gris`). The motor is a **pure function** (zero I/O, zero state, zero randomness — determinismo AC-DEC-04). It applies first 5 hard rules R1–R5 (Chain of Responsibility; first match → `malicioso`), then a 6-row decision table (FR-002) combining `score_final`, `confirmacion_agente` and `verificaciones_incompletas`. The word "seguro" never appears in the output (FR-006, Art. V.1). If a mandatory verification is incomplete, verdict is `revision_manual` (never `sin_indicadores`, FR-003). The agent opinion can raise risk but never override a hard rule (FR-004). No new dependencies. Test doubles: `tests/unit/dobles_decision.py` (factory `entrada_ejemplo()`).
- **Agente de IA sin estado** lives in `src/level2_agent/agente/` (spec 009, module M07). Public API (package `__init__`): `consultar_agente(entrada, *, modelo=None, contador=None, ahora=None) -> ResultadoAgente`, plus `EntradaAgente`, `SalidaAgente`, `ResultadoAgente`, `ModeloLLM` (Protocol), `ContadorLLM`, constants. It is **wired** into `agent.py` via `_agente_zona_gris()` (replaces the old ReAct agent for the 30–75 zone). The agent receives structured evidence (banderas, auth, URLs, adjuntos, VT, score) — never parses raw email. Tools: exactly `[busqueda_vectorial]` (RAG only); `check_ip_reputation` and `jira_integration` were removed. Triple anti-injection defense: PII sanitization + `<correo>` delimiters + prompt security declaration. Output validated against `SalidaAgente` Pydantic schema (max lengths); 1 retry if invalid. Daily LLM call counter (`ContadorLLM`) in MongoDB `phishguard.llm_contador` with TTL, fallback in-memory; configurable via `LLM_MAX_DIARIO` env var (default 100). Model swappable via `ModeloLLM` Protocol + `GeminiAdapter`; `LLM_MODELO` env var (default `models/gemini-2.5-flash-lite`). Temperature fixed at 0. `agent.py` refactor (research D2): removed `_build_react_agent`, `_get_react_agent`, `_parse_agent_response`, `_create_rag_tool`, `ip_reputation_tool` import, direct `create_jira_ticket` call. No new dependencies. Test doubles: `tests/unit/dobles_agente.py` (`ModeloDoble`, `ModeloDobleInvalido`, `ContadorDoble`, `entrada_agente_ejemplo()`).
- **Acciones idempotentes en Gmail y Jira** lives in `src/level2_agent/acciones/` (spec 010, module M08). Public API (package `__init__`): `ejecutar_acciones(entrada, *, gmail=None, jira=None, ahora=None) -> ResultadoAcciones`, plus `EntradaAcciones`, `ResultadoAccion`, `ResultadoAcciones`, `Accion` (enum), `GmailAdapter` (Protocol), `JiraAdapter` (Protocol), `ResultadoJira`, `resolver_acciones`, `calcular_huella`, `sanear_texto_jira`, constants. It is **wired** into `gmail_poller.py` (replaces direct `move_to_label`/`mark_as_read` calls). Table-driven verdict→action mapping (FR-001). DRY_RUN active by default (Art. V.2, `ACCIONES_DRY_RUN` env var). Idempotencia por `message_id` (MongoDB `phishguard.acciones_ejecutadas`, fallback in-memory). Huella de campaña SHA-256[:16] for Jira ticket deduplication (FR-004). Never deletes emails (FR-005, AST gate). Resilience: Jira failure → Gmail continues, error logged, no retry loop (AC-ACT-08). Adapter pattern for Gmail and Jira (testability). No new dependencies. Test doubles: `tests/unit/dobles_acciones.py` (`GmailDoble`, `JiraDoble`, `entrada_acciones_ejemplo()`).
- **Persistencia y métricas** lives in `src/level2_agent/persistencia/` (spec 011, module M14). Public API (package `__init__`): `guardar_analisis(analisis, *, repo=None) -> str`, `calcular_metricas(analisis, *, tz, inicio, fin) -> Metricas`, `sembrar_datos(*, repo, ahora) -> int`, `borrar_analisis(message_id, *, repo, cache_vt) -> bool`, plus `AnalisisPersistido`, `Metricas`, `PorDia`, `RepositorioAnalisis` (Protocol), `RepositorioCacheVT` (Protocol), `RepositorioReal`, `CacheVTReal`, `RepositorioDoble`, `CacheVTDoble`, constants. It is **wired** into `gmail_poller.py` (calls `guardar_analisis` after each analysis) and `agent.py` (helper `construir_analisis_persistido`). TTL retention: `analyses` 90d, `analyses_fallidos` 30d (FR-001). Never persists HTML or attachment content (FR-002, I1/I2). `calcular_metricas` is a pure function (zero I/O). Siembra deterministic: 100 analyses (55/15/30, 60% sin modelo) by formula without randomness (FR-006). Deletion removes analysis + VT cache (FR-005). `por_dia` fills zero days, timezone `America/Bogota` (FR-004). No new dependencies. Test doubles: `tests/unit/dobles_persistencia.py` (`entrada_persistido_ejemplo()`).
- **API REST** lives in `src/api/` (spec 012, module M14). Public API (package `__init__`): `create_app() -> FastAPI`. Routers: `salud` (GET /api/health, sin auth), `integraciones` (GET /api/integraciones, sin claves AC-API-06), `muestras` (GET /api/samples desde fixtures), `analisis` (POST/GET/GET{id}/PATCH/DELETE /api/analyses + export.csv), `metricas` (GET /api/metrics/summary?rango=7d|30d|90d), `jobs` (GET/POST /api/jobs/gmail). Auth: X-API-Key header (AC-API-07, env `API_KEY`). Rate limit: 30 POST /analyses/min por key+IP (in-memory, AC-API-09). CSV export: BOM UTF-8 + formula escape (CWE-1236) + 5000 row cap (AC-API-08). Error envelope: `{error: {codigo, mensaje, detalles}}` (FR-002). Dry run active by default (AC-API-03, Art. V.2). Graceful degradation: VT/model/RDAP caídos → 201 con revision_manual (AC-API-10). Dependencies: fastapi, uvicorn, python-multipart, httpx. Config env vars: `API_KEY`, `CORS_ORIGINS` (comma-separated). Test doubles: `tests/unit/dobles_api.py` (TestClient con RepositorioAnalisisDoble). Entry point: `python -m src.api` or `uvicorn src.api.app:create_app --factory`.
- **Pipeline thresholds** live in `src/level2_agent/models.py`: `SCORE_UMBRAL_BAJO=30`, `SCORE_UMBRAL_ALTO=75`, `SCORE_FALLBACK=50.0`. `analyze_email()` branches on these. The test runner duplicates the 30/75 literals in `detect_route()` — keep them in sync.
- **Genetic weights are loaded from a trained model**: `data/modelo/clasificador_v1.json` contains 32 coefficients + intercept from a logistic regression trained on `100correos.csv` (offline, via `scripts/entrenar_clasificador.py`). Runtime loading: `src/level3_logic/modelo.py` → `cargar_modelo()` with process cache. Scoring: `score = 100 × σ(Σ wᵢ·geneᵢ + b)` (pure Python, zero runtime deps). `MAPEO_INDICES` (32 gene names/order) stays in `genetic_logic.py`; `PESOS_AG` is removed. The scoring facade is `src/level3_logic/scoring/` (`calcular_score_final` composes classifier + banderas 003/004/005 with tope 60). Config via env: `DOMINIOS_PROPIOS`, `*DOMINIOS_PROVEEDORES_CONFIANZA`, `RUTA_MODELO`.
- **LLM model strings**: `models/gemini-2.5-flash-lite` (chat, configurable via `LLM_MODELO` env var in spec 009) in `agente/gemini_adapter.py`, `models/gemini-embedding-001` (embeddings) in `tools/__init__.py`.
- **MongoDB namespaces** are constants in `models.py`: vector store `phishguard.docs_phishing` (index `vector_index`). The README's "create collection `docs_phishing`" refers to this namespace. There is NO chat-history memory since spec 001 (`refactor/eliminar-memoria`): each email analysis is independent.
- **Jira integration** hardcodes project key `SCRUM` and issuetype `Task` in `tools/jira_integration.py`. Only triggers when `report.es_phishing` is true **and** all `JIRA_*` env vars are set.
- **Gmail OAuth**: `credenciales.json` (OAuth desktop creds) at repo root → first poller run opens browser and writes `token.json`. Both are gitignored. Poller moves phishing to label `"Phishing Alertas"` (created/assumed to exist in Gmail).

## Conventions / gotchas

- `.env` is loaded via `python-dotenv` independently in `agent.py`, `gmail_poller.py`, and `test_pipeline.py`. Each entrypoint loads its own — don't assume a central config module.
- All user-facing strings, prompts, and report fields are in **Spanish**. Preserve language when editing `prompts.py`, report generators in `agent.py`, or fixture `_test` metadata.
- `EmailData.headers` is a **JSON string**, not a dict (see `models.py` / `email_to_emaildata.py`). Genetic logic parses it.
- `notebooks/` are exploratory (gene extraction, AG tuning); `_read_nb.py` is a stdin helper that prints notebook cells. `workflow/` holds the architecture diagram. None of these are part of the runtime pipeline.
- There is no formatter, but **ruff + mypy (`--strict`) are configured** in `pyproject.toml` and enforced by `scripts/verify.py` (which also runs `pytest tests/unit/` with branch coverage and a `--cov-fail-under` gate). `hypothesis` is pinned in `requirements.txt` for property-based tests. Match existing style (4-space indent, Spanish docstrings/logs, `Optional` global singletons for lazy init in `agent.py`).
